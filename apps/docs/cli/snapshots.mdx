---
title: ovr snapshots
description: List a build's snapshots and count them by status.
---

Authenticates with a [personal access token](/cli/authentication) — a project API key is rejected.

## `ovr snapshots counts`

```sh
ovr snapshots counts <buildId>
```

| Flag | Description |
|------|-------------|
| `--server-url <url>` | OVR server URL (defaults to `ovr.config`'s `serverUrl`) |
| `-c, --config <path>` | Path to `ovr.config` file |
| `--json` | Print the counts as JSON instead of a table |

Counts the build's snapshots by status, so you can see the shape of a build before
listing anything:

```
STATUS        COUNT
unchanged     41
needs_review  3
error         1
TOTAL         45
```

Only the statuses the build actually has are printed. `--json` returns every status,
including the ones at zero.

## `ovr snapshots list`

```sh
ovr snapshots list <buildId> --status needs_review
```

| Flag | Description |
|------|-------------|
| `--server-url <url>` | OVR server URL (defaults to `ovr.config`'s `serverUrl`) |
| `--status <status...>` | Filter to snapshots with these statuses |
| `--browser <name...>` | Filter to snapshots captured in these browsers |
| `--viewport <name...>` | Filter to snapshots captured at these viewports |
| `--search <text>` | Filter to snapshots matching this text |
| `--limit <count>` | Snapshots per page, 1–100 (default `24`) |
| `--cursor <cursor>` | Fetch the page following this cursor |
| `--all` | Fetch every page instead of just the first |
| `-c, --config <path>` | Path to `ovr.config` file |
| `--json` | Print results as JSON instead of a table |

Prints one row per snapshot: snapshot ID, status, story, browser, viewport, and the
percentage of pixels that differ from the baseline.

```
SNAPSHOT                              STATUS        STORY                        BROWSER   VIEWPORT           DIFF%
01a092d6-b0aa-71bf-9312-dd8ef48a22fb  needs_review  Components/Button / Primary  chromium  desktop 1280x800   1.23
```

`DIFF%` is `-` when the snapshot was never diffed — a first snapshot with no baseline,
or one that errored — and `0.00` when it was diffed and nothing differed. A viewport
captured at the story's full page height rather than a fixed crop prints its height as
`full`.

`--status` accepts `unchanged`, `auto_approved`, `approved`, `needs_review`, `rejected`,
`error`, `canceled`, `skipped`, `queued`, and `processing`; anything else is rejected
before the request is sent. When filters match nothing, the applied filters are printed
alongside `No snapshots found.` so a mistyped browser or viewport is visible.

### Pagination

Pagination works the same way as [`ovr builds list`](/cli/builds): a page at a time,
with the next page's cursor printed when more snapshots match, `--cursor` to resume,
and `--all` to fetch every page at once.

## `ovr snapshots get`

```sh
ovr snapshots get <snapshotId>
```

| Flag | Description |
|------|-------------|
| `--server-url <url>` | OVR server URL (defaults to `ovr.config`'s `serverUrl`) |
| `-c, --config <path>` | Path to `ovr.config` file |
| `--json` | Print the snapshot as JSON instead of formatted text |

Prints the snapshot's ID, status, story, browser, viewport, and image path, plus
whether the page under test threw an uncaught error and its error message when one
was captured.

When the snapshot recorded any console or error logs during capture, they're printed
underneath as a `Logs:` section, one line per entry:

```
Snapshot: 01a092d6-b0aa-71bf-9312-dd8ef48a22fb
Status:   error
Story:    Components/Button / Primary
Browser:  chromium
Viewport: desktop 1280x800
Image:
Uncaught error: yes
Error:    story threw during render

Logs:
  [error] TypeError: Cannot read properties of undefined (2026-09-12T10:43:15Z)
```

## `ovr snapshots download`

```sh
ovr snapshots download <snapshotId> --out ./snapshot-images
```

| Flag | Description |
|------|-------------|
| `--out <dir>` | Directory to write the images into (default `.`) |
| `--server-url <url>` | OVR server URL (defaults to `ovr.config`'s `serverUrl`) |
| `-c, --config <path>` | Path to `ovr.config` file |
| `--json` | Print the written paths as JSON instead of formatted text |

Writes the snapshot's three images — `current.png`, `baseline.png` and `diff.png` —
into `--out` as ordinary PNGs, creating the directory if it doesn't exist.

```
Wrote ./snapshot-images/current.png
Wrote ./snapshot-images/baseline.png
Wrote ./snapshot-images/diff.png
```

An image the snapshot doesn't have is skipped rather than written empty, and named in
the output — a first snapshot with no baseline prints `No baseline or diff image for
this snapshot.` A snapshot with no images at all prints
`No images to download for this snapshot.` rather than failing.
