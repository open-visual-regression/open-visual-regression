## `ovr builds list`

```sh
ovr builds list --branch main --status needs_review
```

| Flag | Description |
| --- | --- |
| `--branch <name...>` | Only builds on these branches |
| `--commit <sha...>` | Only builds for these commits |
| `--status <status...>` | Only builds with these statuses |
| `--author <author...>` | Only builds by these authors |
| `--search <text>` | Only builds matching this text |
| `--sort <direction>` | `asc` or `desc` by creation time. Defaults to `desc` |
| `--limit <count>` | Builds per page, 1–100. Defaults to `20` |
| `--cursor <cursor>` | Fetch the page after this cursor |
| `--all` | Fetch every page |

Prints one row per build: ID, status, branch, commit, project, and name. A filter given several values matches builds that match any of them.

`--status` takes `queued`, `processing`, `needs_review`, `unchanged`, `auto_approved`, `approved`, `rejected`, `error`, and `canceled`.

### Pagination

When more builds match than fit on a page, the command prints the cursor for the next one:

```
Showing 20 of 137. Next page: --cursor eyJjcmVhdGVkQXQiOiIyMDI2...
```

Pass it back with `--cursor`, or use `--all` to fetch every page at once. With `--json`, the cursor is in `nextCursor`, which is `null` on the last page:

```json
{ "builds": [], "total": 137, "nextCursor": "eyJjcmVhdGVkQXQiOiIyMDI2..." }
```

## `ovr builds get`

```sh
ovr builds get <buildId>
```

Prints the build's ID, status, branch, commit, project, name, author, and creation time. A failed build also shows its error, and a canceled one shows who canceled it.

## `ovr builds cancel`

```sh
ovr builds cancel <buildId>
```

Cancels a build that's queued or processing.

## `ovr builds rebuild`

```sh
ovr builds rebuild <buildId> --wait
```

| Flag | Description |
| --- | --- |
| `--wait` | Wait for the new build to finish before exiting |
| `--timeout <seconds>` | How long `--wait` waits. Defaults to `600` |

Captures a finished build again as a new build, from the same upload, and prints the new build's ID. Only the latest build on a branch can be rebuilt. With `--wait`, the command [exits](/cli/installation#exit-codes) like `ovr upload storybook --wait`.

## `ovr builds approve` and `ovr builds reject`

```sh
ovr builds approve <buildId>
ovr builds reject <buildId>
```

Votes on every snapshot in the build that needs review, like **approve all** and **reject all** on the build page, then prints the build's status. When the project needs more than one reviewer, the build stays at `needs_review` until enough people approve it. To vote on one snapshot, use [`ovr diffs approve`](/cli/diffs#ovr-diffs-approve-and-ovr-diffs-reject).

Only the latest build on a branch can be reviewed, once it has finished.
