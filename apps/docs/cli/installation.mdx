---
title: Installation
description: Install the CLI and authenticate it against your OVR server.
---

<CodeGroup>

```sh npm
npm install -D @open-visual-regression/cli
```

```sh pnpm
pnpm add -D @open-visual-regression/cli
```

```sh yarn
yarn add -D @open-visual-regression/cli
```

</CodeGroup>

Or run it without installing:

<CodeGroup>

```sh npm
npx @open-visual-regression/cli
```

```sh pnpm
pnpm dlx @open-visual-regression/cli
```

```sh yarn
yarn dlx @open-visual-regression/cli
```

</CodeGroup>

## Authentication

Every command requires `OVR_API_KEY`, a project-scoped key created from the project's settings page in OVR.

```sh
export OVR_API_KEY=...
```

## Server URL

Every command needs an OVR server URL. Resolved in order: a command's `--server-url` flag, then `serverUrl` in [`ovr.config`](/configuration/config).

## Commands

- [`ovr snapshot storybook`](/cli/snapshot-storybook) uploads a Storybook build and reports the result
- [`ovr builds`](/cli/builds) lists and inspects builds
