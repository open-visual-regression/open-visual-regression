---
title: Installation
description: Install the CLI and point it at your OVR server.
---

<CodeGroup>

```sh npm
npm install -D @open-visual-regression/cli
```

```sh pnpm
pnpm add -D @open-visual-regression/cli
```

```sh yarn
yarn add -D @open-visual-regression/cli
```

</CodeGroup>

Or run it without installing:

<CodeGroup>

```sh npm
npx @open-visual-regression/cli
```

```sh pnpm
pnpm dlx @open-visual-regression/cli
```

```sh yarn
yarn dlx @open-visual-regression/cli
```

</CodeGroup>

## Authentication

Every command reads its credential from `OVR_API_KEY`. See [Authentication](/cli/authentication) for the two kinds of token and which commands take which.

## Server URL

Every command needs an OVR server URL. Resolved in order: a command's `--server-url` flag, then `serverUrl` in [`ovr.config`](/configuration/config).

## Commands

- [`ovr upload storybook`](/cli/upload-storybook) uploads a Storybook build and reports the result
- [`ovr builds`](/cli/builds) lists and inspects builds
- [`ovr snapshots`](/cli/snapshots) lists, counts and inspects a build's snapshots
