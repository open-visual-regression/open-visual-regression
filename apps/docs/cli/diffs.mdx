## `ovr diffs get`

```sh
ovr diffs get <snapshotId>
```

| Flag | Description |
| --- | --- |
| `--download <dir>` | Save the images to this directory: `baseline.png` and `new.png`, and their diff overlays, `baseline-diff.png` with what was removed or changed and `diff.png` with what was added or changed |
| `--analyze` | Describe what changed, such as content that moved |

Takes a snapshot ID, which you can find with [`ovr snapshots list`](/cli/snapshots#ovr-snapshots-list), and shows how the snapshot compares to its baseline. When the project has a [git integration](/manage/git-status-checks), the baseline's commit links to your git provider.

```
Diff:       01a092d6-b0aa-71bf-9312-dd8ef48a22fb
Review:     needs_review
Processing: success
Pixel diff: 1234
Diff %:     1.23
Diff image: project/builds/build/diffs/diff.png
Baseline image: project/builds/prior-build/snapshots/baseline.png
Baseline commit: a1b2c3d
Baseline commit URL: https://github.com/example/repo/commit/a1b2c3d
```

A snapshot with nothing to compare, because it's new or failed, prints `No diff for this snapshot.`

`--analyze` describes the change: how many pixels changed and where, whether the content moved, and whether the image changed size. Content that moves by a few pixels between builds usually points to an animation or something that depends on timing.

```
Analysis:
  15169 pixels changed within 337x718 at 347,61
  Content moved 19px left (explains 100% of the change)
```

## `ovr diffs approve` and `ovr diffs reject`

```sh
ovr diffs approve <snapshotId>
ovr diffs reject <snapshotId>
```

Votes on the snapshot's diff and prints its review status. Voting again replaces your earlier vote. Removing a vote is only possible in the web app.
