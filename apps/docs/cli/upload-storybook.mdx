---
title: ovr upload storybook
description: Upload a Storybook build for OVR to capture and compare.
---

Uploads a Storybook 8.5+ static build (the output of `storybook build`) as a new build. Takes a project [API key](/manage/api-keys-and-tokens#api-keys), and the [global flags](/cli/overview#global-flags).

```sh
ovr upload storybook \
  --dir storybook-static \
  --server-url https://ovr.example.com \
  --branch "$BRANCH" \
  --commit "$COMMIT_SHA" \
  --name "$(git log -1 --pretty=%s)" \
  --author "$(git log -1 --pretty=%an)"
```

## Flags

| Flag | Required | Default | Description |
| --- | --- | --- | --- |
| `-d, --dir <path>` | yes | | Path to the Storybook static build |
| `--branch <name>` | yes | | Branch name |
| `--commit <sha>` | yes | | Commit SHA |
| `--pull-request <number>` | no | | Pull request number. The build page links to the pull request when the project has a [git integration](/manage/git-status-checks) |
| `--name <name>` | no | | Build name, such as the commit message |
| `--author <author>` | no | | Commit author |
| `--wait` | no | `false` | Wait for the build's result before exiting |
| `--timeout <seconds>` | no | `600` | How long `--wait` waits |
| `--only-affected` | no | `false` | Only capture the stories a change can affect. See [Capture only affected stories](/storybook/only-affected) |

Without `--wait`, the command prints the build's URL and exits as soon as the upload is done. With `--wait`, it waits for OVR to capture and compare the build, and its [exit code](/cli/overview#exit-codes) tells your CI whether the build passed.
