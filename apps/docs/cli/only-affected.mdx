---
title: Only affected stories
description: Capture only the stories a change can affect with ovr upload storybook --only-affected.
---

`ovr upload storybook --only-affected` captures only the stories a change can affect. Every other story is listed on the build as skipped and keeps its baseline.

```sh
storybook build --stats-json

ovr upload storybook --dir storybook-static --only-affected \
  --branch "$BRANCH" --commit "$COMMIT_SHA"
```

## Requirements

- Storybook built with the Vite builder and `--stats-json`.
- `ovr` run from the directory Storybook was built in.
- The full git history. In GitHub Actions, check out with `fetch-depth: 0`.
- A successful build on the project's main branch. Changes are compared against the latest one in the commit's history.

If any of these are missing, every story is captured and the CLI prints why.

## What gets captured

A story is captured when a file it imports changed, directly or through other modules and packages. Every story is captured when a change could affect all of them, such as Storybook configuration, dependencies, build configuration, or a stylesheet the Storybook loads globally.

Stories without a baseline for a viewport are always captured on that viewport.

The CLI prints how many stories are affected and which changed file affects each one.

## Configuration

Use [`onlyAffected`](/configuration/config#only-affected) in `ovr.config` to list files that affect every story without being imported, such as a static folder, or files that never affect a story.

```ts
// ovr.config.ts
export default defineConfig({
  onlyAffected: {
    externals: ["public/**"],
    untraced: ["fixtures/**/*.json"],
  },
});
```

## Recommended CI setup

Use `--only-affected` for pull requests and capture every story on the main branch. Full captures on main keep every baseline current.

```yaml
- uses: actions/checkout@v4
  with:
    fetch-depth: 0

- name: Build Storybook
  run: pnpm build-storybook --stats-json

- name: Upload to OVR
  env:
    OVR_API_KEY: ${{ secrets.OVR_API_KEY }}
  run: |
    npx @open-visual-regression/cli upload storybook \
      --dir storybook-static \
      --branch "${{ github.head_ref || github.ref_name }}" \
      --commit "${{ github.event.pull_request.head.sha || github.sha }}" \
      ${{ github.event_name == 'pull_request' && '--only-affected' || '' }}
```

## Limitations

A skipped story can miss a change that doesn't come through an import, such as data fetched at runtime, environment variables, or files in a static folder not listed in `externals`. The next full capture on the main branch picks these up.
