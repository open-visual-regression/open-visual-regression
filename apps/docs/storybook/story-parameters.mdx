---
title: Story parameters
description: Change a story's viewports, diff threshold, or capture settings, or skip it.
---

[`ovr.config`](/reference/ovr-config) sets the viewports every story is captured at and the diff threshold that decides when a change needs review. A story that doesn't fit those defaults overrides them with Storybook's `parameters.ovr`, which OVR reads from the build you upload.

```tsx
// Button.stories.tsx
export const Primary: Story = {
  parameters: {
    ovr: {
      viewports: ["mobile", { width: 1440 }],
      diffThreshold: 0.02,
    },
  },
};
```

| Field | Type | Description |
|-------|------|-------------|
| `viewports` | `(string \| { browser?, width, height? })[]` | Replaces (not merges with) the config's default viewport list for this story. String entries reference a `name` from `ovr.config.ts`; object entries define a one-off viewport inline |
| `diffThreshold` | `number` | Replaces the config's `diffThreshold` for this story, as a fraction of pixels that may differ |
| `waitForTimeout` | `number` | Replaces the config's `waitForTimeout` for this story, in milliseconds. See [Content that loads late](/storybook/stable-screenshots#content-that-loads-late). Set `0` to turn off a wait set in the config |
| `blockExternalRequests` | `boolean \| { allow: string[] }` | Replaces the config's `blockExternalRequests` for this story. See [Blocking external requests](/reference/ovr-config#blocking-external-requests) |
| `screenshotStability` | `"auto" \| "always" \| "off"` | Replaces the config's `screenshotStability` for this story. See [Stable screenshots](/storybook/stable-screenshots#animations-caught-mid-frame) |
| `skip` | `boolean` | Skips this story; it is listed on the build as skipped, never captured or diffed |

Storybook merges parameters global → component → story, so the same block on a `meta` default export covers every story in the file, and in `.storybook/preview.ts` every story in the project. The most specific level wins.

## Skipping stories

`skip: true` stops OVR from capturing a story, so it has nothing to review. It's still listed on every build as `skipped`, so you can see which stories aren't checked. Use it for stories that can't produce a [stable screenshot](/storybook/stable-screenshots).

```tsx
export const LiveFeed: Story = {
  parameters: { ovr: { skip: true } },
};
```

Skipping keeps the story's baselines, so when you stop skipping it, it's compared with the baseline it had.
