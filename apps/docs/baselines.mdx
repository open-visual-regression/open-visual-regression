---
title: Baselines
description: Find a project's baseline build and link to its Storybook.
---

A project's baseline build is its latest successful build on its main branch. Builds on the main branch are approved automatically, so each one becomes the baseline its later builds are diffed against.

Open it from a project's page with **view baseline**.

## Branch builds

A build on any other branch is compared against main as it was when the branch was cut, not main's latest. Changes that landed on main since then don't show up as changes on the branch, so a branch that's behind main only shows its own changes.

The CLI finds the most recent successful main-branch build in the commit's history and sends it with the build. The build page shows it next to the branch, the way a pull request shows its base branch: `main @ c0ffee1 ← feature/empty-state`, with the main side linking to that build. When there's no such build, it shows `main (latest)`. A branch build is compared against main's latest baselines when:

- The git history isn't available, such as in a shallow clone. In GitHub Actions, check out with `fetch-depth: 0`.
- No successful main-branch build is in the commit's history.
- The main-branch build has been removed by the project's retention period.

If main changed a snapshot after the branch was cut and the build holding its earlier screenshot has been removed, that snapshot is also compared against main's latest. Capturing everything on every main build keeps those screenshots as recent as possible.

## Stable links

These links always point at the current baseline, so you can put them in docs, READMEs, or a design system site. Replace `https://ovr.example.com` with your OVR URL and `<project-id>` with the ID from the project's URL.

| Link | Opens |
|------|-------|
| `https://ovr.example.com/api/baseline/<project-id>` | The baseline build |
| `https://ovr.example.com/api/baseline/<project-id>/storybook` | The baseline build's Storybook |

To link to a single story, add Storybook's `path` parameter:

```text
https://ovr.example.com/api/baseline/<project-id>/storybook?path=/story/ui-button--primary
```

Opening a link requires signing in to OVR. After signing in, you're taken to the link you opened. A project with no baseline build yet returns a 404.
