---
title: ovr.config
description: Set the server URL, viewports, diff threshold, and capture settings for a project.
---

An `ovr.config.ts` (or `.js`/`.mjs`) file in the directory you run the CLI from configures the server URL, capture viewports, and diff threshold for a project.

```ts
// ovr.config.ts
import { defineConfig } from "@open-visual-regression/cli/config";

export default defineConfig({
  serverUrl: "https://ovr.example.com",
  viewports: [
    { name: "desktop", width: 1280 },
    { name: "mobile", width: 375, browser: "webkit" },
  ],
  defaultViewports: ["desktop"],
  diffThreshold: 0.05,
});
```

## Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `serverUrl` | `string` | | OVR server URL. Overridden by a command's `--server-url` flag |
| `viewports` | `Viewport[]` | `[]` | Every viewport available, named or not |
| `defaultViewports` | `string[]` | every named viewport | Names from `viewports` to capture by default |
| `diffThreshold` | `number`, `(0, 1]` | `0.05` | Fraction of pixels that may differ before a snapshot needs review |
| `waitForTimeout` | `number`, `[0, 30000]` | `0` | Milliseconds to wait before each screenshot, e.g. for slow-loading data or images |
| `blockExternalRequests` | `boolean \| { allow: string[] }` | `false` | Blocks requests to hosts outside your build. See [below](#blocking-external-requests) |
| `screenshotStability` | `"auto" \| "always" \| "off"` | `"auto"` | When to retake a screenshot until two in a row match. See [Stable screenshots](/storybook/stable-screenshots#animations-caught-mid-frame) |

<Note>
If `viewports` is omitted, OVR falls back to a single default: 1280px wide, full page, in Chromium.
</Note>

## Viewports

Each entry in `viewports` describes one capture target:

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `name` | `string` | | Refers to this viewport from `defaultViewports` or [story parameters](/storybook/story-parameters) |
| `browser` | `"chromium" \| "firefox" \| "webkit"` | `"chromium"` | |
| `width` | `number` | | |
| `height` | `number` | full page | Omit to capture the full page height instead of a fixed crop |

A viewport without a `name` is never captured by default, since `defaultViewports` can't refer to it.

A Storybook story can override these for itself with [story parameters](/storybook/story-parameters).

## Blocking external requests

By default, a capture loads whatever the page requests. Set `blockExternalRequests` to keep screenshots from depending on other hosts:

| Value | Loads |
|-------|-------|
| `false` (default) | Every host |
| `true` | Only your uploaded build |
| `{ allow: [...] }` | Your uploaded build and the listed hosts |

This includes requests a service worker like [msw](https://mswjs.io) passes through to the network. To keep loading images and fonts from a CDN:

```ts
export default defineConfig({
  blockExternalRequests: {
    allow: ["images.example.com", "fonts.googleapis.com", "fonts.gstatic.com"],
  },
});
```

Each entry is a host (`example.com`), a host and port (`example.com:8443`), or `*.example.com` for its subdomains. A snapshot that requested a blocked host gets a warning in its logs naming the host.

<Note>
Firefox ignores ports, so `example.com:8443` allows every port there.
</Note>

## Storybook

### Only affected

`onlyAffected` sets options for [capturing only affected stories](/storybook/only-affected). Globs are relative to the directory you run the CLI from.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `externals` | `string[]` | `[]` | Files that affect every story when they change, such as a static folder |
| `untraced` | `string[]` | `[]` | Files that never affect a story |
